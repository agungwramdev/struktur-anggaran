QUICK START - STRUKTUR ANGGARAN
================================

INSTALASI:

1. Backend:
   cd backend
   npm install
   npm run start:dev

2. Frontend (terminal baru):
   cd frontend
   npm install
   npm run dev

3. Akses: http://localhost:3000
   Login: superadmin / admin123

================================

CATATAN PENTING:
- Pastikan MongoDB berjalan di localhost:27017
- Backend berjalan di port 3001
- Frontend berjalan di port 3000
- Superadmin otomatis dibuat saat pertama kali backend dijalankan
